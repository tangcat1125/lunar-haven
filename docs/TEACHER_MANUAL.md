## 一、 教師管理後台進入與配置指南

### 1. 後台進入方式
無論是在首頁導引網頁（Landing Page）右上角，或是進入主遊戲後的**頂部 HUD 標籤（`🎯 目標設定 / ⚙`）**，點擊即可**免密碼直接展開結束條件設定面板**！隨選隨套用，極速靈活。

### 2. 結束條件與教學情境下拉選單設定

| 選單項目 | 適用課堂情境 | 運作規則與結束判定 | 預期教學成效 |
|---|---|---|---|
| **1. 完整朔望月流程 (29.5天)** | 課後作業 / 專案探究 | 系統跑完一整輪 29.5 天農曆循環後自動結算。 | 學生完整掌握 8 大月相演變與前後因果。 |
| **2. 半週期精華 (初一至十五)** | 40 分鐘標準課堂教學 | 從朔月至暗狼襲開始，賽跑至滿月異變檢驗結束。 | 體驗「防守失敗 ➜ 狼毒潛伏 ➜ 滿月異變」閉環。 |
| **3. 死傷／狼化門檻 (1/3/5人)** | 團隊防禦挑戰賽 | 當受傷村民狼化或陣亡達門檻即判定小鎮淪陷。 | 刺激學生進行精準資源調度與緊急醫療。 |
| **4. 成功抵禦指定次數危機** | 分組競賽模式 | 成功挺過 1 次朔月 + 1 次滿月危機即通關。 | 檢驗防禦設施與解藥儲備策略。 |
| **5. 集齊 8 大月相圖鑑** | 天文認知強化專題 | 學生需在觀察手冊中點亮並填寫 8 種月相名稱。 | 強化形狀、朝向與農曆日期的精準配對。 |
| **6. 課堂限時模式 (15/30/40分)** | 限時課堂演練 | 時間倒數歸零立即鎖定畫面並彈出報告。 | 配合課堂鐘聲進行統一結算。 |

## 二、 學習評量報告（天文守夜者手冊）結構

當學生達成教師設定之條件後，遊戲自動產出《小鎮守夜者天文手冊》結算學習單：
1. **天文月相識別度評分（40%）**：
   - 朔月、眉月、上弦月、滿月、下弦月、殘月之辨識正確率。
2. **農曆與公曆對應分析（20%）**：
   - 是否理解初一無月、初七/八上弦、十五滿月、廿二/三下弦的固定規律。
3. **生態防禦與因果決策（30%）**：
   - 朔月狼群入侵防禦率（捕獸夾、鐵圍籬、衛兵準備度）。
   - 狼毒感染控制率（附子草採集量、解藥熬製量、治癒成功人數）。
4. **小鎮繁榮評級（10%）**：
   - 依據終局存糧、小鎮警戒值與居民健康狀況評定 S / A / B / C / D。
5. **一鍵匯出功能**：
   - 支援 `[ 列印成果學習單 / 另存為 PDF ]`，方便學生繳交紙本或截圖上傳學習平台。
