# 《月痕小鎮》（Lunar Haven）

> **結合真實天文週期的橫向捲軸放置型教學遊戲**  
> 純前端零依賴架構，直接在 Windows 中雙擊 `index.html` 即可於任意瀏覽器秒速啟動！無需安裝 Node.js 或架設虛擬伺服器。

---

## 快速開始（本機直接執行）

1. 打開本資料夾：`d:\game\lunar-haven\`
2. **直接雙擊 `index.html`**，即刻透過 Chrome、Edge 或 Firefox 開始遊玩。
3. 遊戲首頁點擊 **`[ 踏入小鎮 / 開始守望 ]`** 進入長卷大世界。
4. 右上角設有 **`⚙ 教師設定`**，輸入預設密碼 `haven2026` 或 `lunar888` 即可自訂課堂結束條件。

## 核心教學機制亮點

1. **真實天文週期與北半球視角月相**：
   - 朔月（初一）、眉月（初二～六）、上弦月（初七～八）、盈凸月（初九～十三）、望月/滿月（十四～十六）、虧凸月（十七～廿一）、下弦月（廿二～廿三）、殘月（廿四～廿八）。
   - 朝向嚴格符合客觀天象（右亮為盈、左亮為虧）。
2. **因果閉環防守機制**：
   - **朔月至暗期（廿八～初二）**：伸手不見五指，野狼夜襲。若防守不足，居民受咬傷（立繪浮現爪痕紫斑）。
   - **狼毒賽跑期（初三～十三）**：指派草藥女艾莉採附子草、修士奧古斯熬解藥、修女克萊兒包紮照料。
   - **滿月銀月期（十四～十六）**：未癒傷患旋轉翻面（Card Flip）化為狂暴狼人！衛兵雷蒙消耗銀劍壓制。
3. **厚紙卡剪裁繪本美學（Paper-Cut Standee）**：
   - 雙層白卡邊、側切厚度、左右微擺步伐（Waddling Walk）、立繪滑入與紙牌翻面。
4. **《小鎮守夜者天文手冊》學習單結算**：
   - 自動統計天象認知評分、防禦決策分析與導師評語，支援一鍵列印成紙本作業。
5. **玩家守望點數（行動點數）與跨回合累存機制**：
   - **HUD 即時顯示**：頂部 HUD 清楚呈現玩家當前擁有的守望點數。
   - **每次指派消耗 1 點**：每次與 NPC 對談委派任務或救治傷患皆需消耗 1 點守望精力。
   - **點數耗盡即換日**：點數用完不能對談，小鎮直接進入守夜並自動前進至下一天！
   - **回合存點戰略**：每回合沒用完的點數可完整存起來留到下一回合累積使用（上限 12 點，每日補給 +3 點），鼓勵學生謹慎決策並在危機日前囤積點數！
